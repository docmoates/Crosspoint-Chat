Write the OpenRouter adapter for our ChatProvider interface. It needs streaming, tool calls and a usage event at the end. Check what the current OpenRouter docs say about the reasoning param.
Claude Sonnet 5.5 · via OpenRouter

Thinking
The interface wants an AsyncIterable of typed events. OpenRouter follows the OpenAI Chat Completions shape, so I will wrap the SSE stream and map delta.tool_calls into tool_call events, buffering arguments by index until finish_reason arrives. Usage comes in the final chunk when stream_options.include_usage is set.

OpenRouter takes a single reasoning object with either effort or max_tokens, and streams the reasoning text back as delta.reasoning. Usage arrives in the last chunk when you set stream_options.include_usage. Here is the adapter:

openrouter.ts19 lines
export async function* stream(req: ChatRequest): AsyncIterable<ChatEvent> {
  const res = await fetch(`${BASE}/chat/completions`, {
    method: "POST",
    headers: { Authorization: `Bearer ${key}`, "Content-Type": "application/json" },
    body: JSON.stringify({
      model: req.model, messages: toOpenAI(req.messages), tools: req.tools,
      stream: true, stream_options: { include_usage: true },
      reasoning: req.effort ? { effort: req.effort } : undefined,
    }),
  });
  for await (const chunk of sse(res.body)) {
    const d = chunk.choices?.[0]?.delta;
    if (d?.reasoning) yield { type: "thinking", text: d.reasoning };
    if (d?.content)   yield { type: "text", text: d.content };
    if (d?.tool_calls) yield* bufferToolCalls(d.tool_calls);
    if (chunk.usage)  yield { type: "usage", ...chunk.usage };
  }
  yield { type: "done" };
}
